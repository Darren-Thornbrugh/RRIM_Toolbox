# Contributing to RRIM Tools for ArcGIS Pro

Thank you for your interest in contributing.  
This project welcomes improvements, bug fixes, documentation updates, and new ideas.

---

## How to Contribute

### 1. Reporting Issues
Please include:

- ArcGIS Pro version  
- Operating system  
- DEM resolution and size  
- Steps to reproduce  
- Error messages or screenshots  

### 2. Submitting Pull Requests
- Fork the repository  
- Create a feature branch  
- Make changes in small, focused commits  
- Ensure code is clear and documented  
- Submit a pull request describing the change  

### 3. Coding Guidelines
- Use clear, readable Python  
- Avoid external dependencies  
- Maintain ArcGIS Pro compatibility  
- Follow existing code style  

### 4. Adding New Tools
If proposing a new tool:

- Describe the purpose  
- Provide algorithmic references  
- Include example outputs  

---

## Code of Conduct
Be respectful, constructive, and collaborative.
